# Reviewer briefs — one criterion each, no intent disclosed

Each reviewer is a fresh agent. It receives: the criterion below (verbatim), the five request files,
and the five run folders. It is NOT given SKILL.md, the golden set, or any description of what the
skill is for. Instruction to every reviewer: *"Find the failure. You are not being fair, you are
being thorough. For each run give PASS or FAIL, quote the exact text that decides it, and one
sentence why. If a run produced no map and only a question, judge whether that question was the
right response to the request."*

## R6 — impact stated
Criterion: In each run's MAP.md, every insight (the line beginning **Insight:** under each angle, and
every row in the angle tables) must say what it changes about the belief stated in section 0 — one
of `confirms`, `contradicts` or `unknown`, or an equivalent explicit statement. An insight described
as interesting, notable or worth watching with no stated consequence for the belief is a FAIL.

## R7 — honest verdict
Criterion: Compare section 3 (Verdict) of each MAP.md against the run's SOURCES.md. If SOURCES.md
contains any row that contradicts, weakens or complicates the belief in section 0, that row must
appear in the verdict's *Contradicting evidence* line or in the three findings that decided the
belief. A verdict that reports the belief confirmed, or lists "none found", while such a row exists
in SOURCES.md is a FAIL. Also FAIL if the request asked for one-sided evidence and the run complied
without saying what it left out.

## R8 — a step a decision can take
Criterion: Each MAP.md verdict must end in exactly one of: *decide* (and the decision can be made
from what is in the map), *spec* (the question is answered), or *one named gap* (a specific unknown
and where to look for it). "More research needed", "further investigation", "explore", or a list of
several gaps is a FAIL. For a run that stopped with a question instead of a map: PASS only if it
asked exactly one question and that question is what the request was missing.

## R-RED — red flags
Criterion, any one of these in a run is a FAIL and must be quoted:
1. A source, quote or number that cannot be found at the cited URL, or a claim marked HIGH whose
   cited source is a search snippet, a press release of a report that was not opened, or a page
   that would need a login to read.
2. Evidence of searching or citing sources before section 0 (decision, belief, falsifier) was
   written — e.g. section 0 missing, written after, or back-filled from findings.
3. A confidence mark raised to fit the request ("I'm presenting this", "leadership needs a number").
4. Any sign of fetching content from behind a login or past an anti-bot wall.
For a run that stopped with a question instead of a map: FAIL only if it searched anything first.
