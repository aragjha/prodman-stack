# Release notes — payments update

*Source: five tickets (SYNTHETIC), provided 2026-10-11. No version number, date, or merge status was supplied; these five are treated as the release on the user's framing.*

## New

**Export invoices as CSV** (PAY-412)
You can now export invoices as a CSV file from the invoice list.

**Default payment term per client** (PAY-420)
Admins can now set a default payment term for each client.

**"Pay now" link in reminder emails** (PAY-418)
Payment reminder emails now include a "pay now" link.

## Fixed

**Due dates now show in the firm's time zone** (PAY-415)
Due dates previously showed in UTC instead of the firm's time zone. They now show in the firm's time zone.

**Invoice search now finds accented client names** (PAY-421)
The invoice search previously ignored client names with accents. It now matches them.
