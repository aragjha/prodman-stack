## Long-form release notes (for a changelog or help centre)

### New

**Export invoices as CSV (PAY-412)**
Invoices can now be exported as a CSV file directly from the invoice list.

**Set a default payment term per client (PAY-420)**
Admins can now set a default payment term for each client. New invoices for that client start with
the term already applied.

**"Pay now" link in payment reminders (PAY-418)**
Payment reminder emails now include a "pay now" link.

### Fixed

**Due dates now use the firm's time zone (PAY-415)**
Due dates previously displayed in UTC. They now display in the firm's time zone.

**Invoice search now matches accented client names (PAY-421)**
Invoice search previously ignored client names with accents. Searching now matches those names.
